# Boosty

Реклама в Telegram-каналах Узбекистана без крипты. Бизнес выбирает каналы, загружает пост и платит в сумах.
Админы каналов принимают заказ в боте, публикуют пост и получают деньги после 24 часов. Сервис берёт комиссию.

## Что уже есть

| Кто | Что может |
|---|---|
| **Бизнес** | Регистрация по телефону, каталог каналов по тематикам, прогноз просмотров и цены, заказ с текстом поста, оплата (пока тестовая), отчёт: просмотры, переходы, цена перехода, возвраты |
| **Админ канала** | Добавить канал на проверку, менять цену и ставить паузу, принимать и отклонять заказы на сайте или в боте, отмечать публикацию ссылкой на пост, видеть выплаты |
| **Владелец** | Проверка новых каналов, контроль опубликованных постов, закрытие с выплатой или возвратом, список выплат админам, оборот и комиссия за 30 дней |
| **Автоматика** | Короткие ссылки `/r/КОД` считают переходы из каждого канала; воркер собирает просмотры, через 24 часа закрывает пост и начисляет выплату, а если пост удалён раньше, делает возврат; уведомления в Telegram |

## Как устроены деньги

1. Клиент платит: цена админа + комиссия (по умолчанию 15%, `NEXT_PUBLIC_COMMISSION_PERCENT`).
2. Деньги «заморожены», пока админ не опубликует пост и он не провисит 24 часа.
3. Пост провисел → админу начисляется выплата (видно в панели владельца, выплачиваете вы и нажимаете «Отметить выплаченным»).
4. Админ отказал или удалил пост раньше → сумма поста с комиссией идёт в возврат клиенту.

## Запуск на своём компьютере

Нужны Node.js 20+ и Docker (или любой PostgreSQL).

```bash
cp .env.example .env          # заполните AUTH_SECRET, OWNER_PHONE, OWNER_PASSWORD
docker compose up -d          # база PostgreSQL
npm install
npm run db:push               # создать таблицы
npm run db:seed               # тематики, аккаунт владельца, демо-каналы
npm run dev                   # сайт на http://localhost:3000
```

Войдите номером `OWNER_PHONE`. Демо-каналы принадлежат владельцу, поэтому весь путь можно пройти одному:
зарегистрируйте второй аккаунт бизнеса → закажите рекламу в демо-канале → оплатите (тестово) →
войдите владельцем → «Заказы каналов» → примите и вставьте любую ссылку вида `https://t.me/demo_avto_news/1`.

## Telegram-бот (уведомления админам и клиентам)

1. Создайте бота у [@BotFather](https://t.me/BotFather), впишите `TELEGRAM_BOT_TOKEN` и `TELEGRAM_BOT_USERNAME`.
2. `npm run bot`
3. В кабинете админа появится кнопка «Подключить бота». В боте команда `/zakazy` показывает новые заказы с кнопками.

## Сбор просмотров

Bot API не отдаёт просмотры постов, поэтому воркер работает от имени обычного служебного аккаунта Telegram.

1. Ключи `TG_API_ID` и `TG_API_HASH` на <https://my.telegram.org>.
2. `npm run stats:login` → строку сессии в `TG_SESSION`.
3. `npm run stats` — проверяет посты каждые 30 минут.

Пока воркер не запущен, владелец закрывает посты вручную в панели.

## Что сделать перед запуском для настоящих клиентов

- **Оплата.** Сейчас кнопка оплаты тестовая (`payStub` в `src/app/actions/orders.ts`). Нужны договоры с Click/Payme и обработчики их уведомлений: после подтверждения платежа вызвать `markOrderPaid()` из `src/lib/orders.ts`.
- **Возвраты.** Сейчас считаются в заказе (`refunded`), но деньги возвращаются вручную. Потом можно сделать баланс клиента.
- **Реальные каналы.** Удалите демо-каналы (`isDemo = true`) и пригласите админов. Проверяйте просмотры в TGStat перед одобрением.
- **Юридическая часть.** Договор-оферта для клиентов и админов, оформление компании для приёма платежей.
- **Хостинг.** Сайт (Vercel, Railway или свой сервер), PostgreSQL, а бот и воркер как постоянно работающие процессы (например pm2 на VPS).

## Структура

```
prisma/schema.prisma     модели: пользователи, каналы, заказы, размещения, переходы, платежи, выплаты
prisma/seed.ts           тематики, владелец, демо-каналы
src/lib/pricing.ts       цена, комиссия, прогноз просмотров
src/lib/orders.ts        статусы заказа, выплаты и возвраты
src/app/                 страницы: главная, каталог, заказ, кабинеты, панель владельца
src/app/actions/         серверные действия (регистрация, заказы, админ, владелец)
src/app/r/[code]/        короткие ссылки и подсчёт переходов
bot/index.ts             Telegram-бот
worker/stats.ts          сбор просмотров и закрытие постов
```
